Modifiers: ctrl, alt, shift, win/cmd (Windows key isn't supported on Windows).
Named keys: enter, tab, esc, space, backspace, delete, up/down/left/right, home, end, pageup, pagedown, insert, f1-f12.
Or a single character, e.g. "a" or "ctrl+z". This sends straight to the OS - Fusion doesn't need to be running.
